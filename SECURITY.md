# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**, through GitHub's private vulnerability reporting for this
repository: open the **Security** tab and choose **Report a vulnerability**. Please do not open a public
issue or pull request for a vulnerability, and do not post details anywhere public before a fix is out.

A report is most useful with the version or commit, the steps to reproduce it and what you expect to
happen instead.

## Supported versions

Only the `main` branch is supported. Fixes go to `main`; there are no backports to older commits or
tags.

## What to expect

This is an unofficial community fork maintained on a best-effort basis. There is no promise of a
response time or of a fix date.

## Scope

This policy is for this repository, Quillpick. Problems in the upstream project
([Rizzo Flow](https://github.com/Rizzo-AI-Academy/rizzo-flow)), in llama.cpp, in the Spark models or
in any other dependency should be reported to their own projects; if you are not sure where a problem
belongs, report it here.
